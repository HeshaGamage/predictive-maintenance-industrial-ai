A predictive maintenance system for industrial assets, inspired by IFS.ai's 
Industrial AI architecture. Combines machine learning failure prediction, 
SHAP-based explainability, and an LLM-powered agent that generates structured 
work orders — demonstrating the full sense → decide → act loop.
